
CodeBuddy配置方法

=== 第一步 ===
CodeBuddy打开Settings → MCP → Add MCP，粘贴以下内容 

{
  "mcpServers": {
   
  "gm-data-bridge": {
    "transport": "stdio",
    "command": "python",
    "args": ["<你的项目路径>/mcp_service.py", "--stdio"],
    "disabled": false,
    "description": "数据收发桥：其他程序通过 base_url+api_key 推送文本/图片，AI 通过工具读取"
  }

  }
}


=== 第二步 ===

1、双击 run.bat 启动服务（显示 base_url 和 api_key）
2、打开AI插件的窗口、选择需要的模型（不可选的忽略），在 Craft 模式输入“循环调用 get_new_data（wait_seconds=15），循环100次” 即可调用 get_new_data 读取其他程序发过来的内容
3、其他程序：POST http://127.0.0.1:8765/receive（带 X-API-Key）推送文本/图片

其他程序的使用方式：
base_url: http://127.0.0.1:8765
api_key: dk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx（首次运行自动生成，见 config.json 或启动窗口输出）

可以用附带的UI工具进行验证。

说明：
游标机制：程序里维护 after_id（上次读到的最大编号），每次 receive_results 后更新
长轮询：wait_seconds=10 表示没新结果时服务端等 10 秒再返回，比频繁轮询省事（外部程序可放心用 60 秒）
AI 侧配合：AI 收到数据后必须调用 send_result 结果才会出现在 /responses 里
